# Exercises

The five practice exercises from the course, each with the statement, a template to start from,
and the solution we wrote together.

| | Exercise | Needs |
|---|---|---|
| 01 | One operation, three async styles | internet |
| 02 | Load a dashboard in parallel | internet |
| 03 | Send five jobs, but keep every result | internet |
| 04 | Search box: cancel the old request | `node local-server.js` in a second terminal |
| 05 | Order Builder: render, one listener, state, save | `node server.js` in the folder |

Start from `template/`, run the file after every step, and open `solution/` when you are stuck
for more than ten minutes.
